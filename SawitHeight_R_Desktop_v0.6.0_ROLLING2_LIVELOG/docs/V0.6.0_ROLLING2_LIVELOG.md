# v0.6.0 — Rolling 2-Period, Residual Confidence & Live Log

## Perubahan dari v0.4.1

- Arsitektur monitoring berubah dari current-period + previous-result SHP menjadi dua point cloud terakhir yang dianalisis bersama.
- Common DTM tidak wajib; PREV dan CURR memiliki terrain mode terpisah.
- Ditambahkan hold-out terrain QC, presence support, metric disagreement, T_TECH, peer-based lower residual limit.
- Stable delta tidak otomatis menjadi residual.
- Residual buffer dapat didissolve menjadi operational residual zones.
- Histori berat tidak perlu diproses ulang untuk residual terbaru.
- UI memiliki live log, heartbeat, elapsed time, dan last-output idle monitor.

## Registration

Master period bersifat opsional. Aplikasi menyimpan metadata reference tetapi tidak melakukan ICP atau rigid transformation otomatis. Pengguna wajib mengonfirmasi alignment horizontal sebelum residual analysis dijalankan.

## Shapefile field policy

Field output SHP sengaja disingkat agar aman terhadap batas nama field DBF 10 karakter. CSV menyimpan nama variabel lengkap.
